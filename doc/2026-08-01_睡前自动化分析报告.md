## ① 抖音出包后平台切换 / 工具消失根因

### 现象复现
1. 编辑器停在默认平台，"ByteGame/抖音工具" 菜单可见。
2. 点 `Tools/铲屎官疯了/抖音小游戏一键出包`（或跑 `tools/build_douyin.ps1`）。
3. 出包结束后 → **活动目标被切走** + **"抖音工具/ByteGame"菜单消失**。
4. 必须手动去 `ByteGame → Platform Plugin List / 子平台面板` 重新启用。

### 根因（证据链）

**第 1 环：构建脚本硬编码切错了目标**

`Assets/Scripts/Editor/AutoBuildDouyin.cs:67-74`：
```csharp
// 1. 切换平台到 MiniGame
var mgTarget = (BuildTarget)36;   // MiniGame enum value
var mgGroup  = (BuildTargetGroup)34; // MiniGame enum value
if (EditorUserBuildSettings.activeBuildTarget != mgTarget)
{
    Debug.Log("[AutoBuild] 切换平台到 MiniGame...");
    EditorUserBuildSettings.SwitchActiveBuildTarget(mgGroup, mgTarget);
}
```

**第 2 环：本工程实际配置的抖音目标是另一个**

| 来源 | 目标 | 证据 |
|---|---|---|
| `AutoBuildDouyin.cs:68-69` | 硬编码 `(BuildTarget)36` / `(BuildTargetGroup)34` | 源码 |
| `MiniGame1Build.cs:30-31` | `BuildTarget.MiniGame` / `BuildTargetGroup.MiniGame`（具名枚举） | 源码 |
| `New DouYin Profile.asset:15-17` | `m_BuildTarget: 47`、`m_Subtarget: 3`、`m_ModuleName: WeixinMiniGame` | 资产 |
| `ProjectSettings/ProjectSettings.asset:349/627-628/649` | 只有 `WeixinMiniGame` 键 | 设置 |
| `Editor.log:290` | `Register platform support module: WeixinMiniGameSupport/...` | 引擎日志 |

**结论**：工程真正配置好的抖音出包目标是 `WeixinMiniGame(47) + subtarget=3`（抖音），而出包脚本却切了一个**完全不同的 `MiniGame(36)`**——二者不是同一个目标。

**第 3 环：抖音工具是跟目标走的子平台**

团结引擎日志（`C:/Users/Lionel/AppData/Local/Tuanjie/Editor/Editor.log:297-322`）显示：抖音是挂在 WeixinMiniGame 目标下、通过 `entitlement` 动态加载的 **子平台**，不是独立平台。  
`LocalPackages/com.bytedance.starksdk@6.7.9/Editor/Extras/Integration/DouYinSubplatformInterface.cs:9-16` 在每次域重载时按当前活动目标重新挂载 → 目标一切走，子平台就丢了。

**第 4 环：脚本既不恢复目标，也不重挂子平台**

- `AutoBuildDouyin.cs:158-172` 出包结束直接返回，没有 "切回原目标" 也没有 "重挂子平台" 逻辑。
- 全工程 grep `SwitchActiveBuildTarget` / `activeBuildTargetChanged` / `[InitializeOnLoad]`：**没有任何用户代码**监听构建目标变化或自动重挂抖音子平台。
- 唯一相关的 `[InitializeOnLoadMethod]` 是 `AddressablesBootstrap.cs:25-33`，只建 Addressable 组，**完全不碰 build target**。

### 修复方案（推荐 A）

**方案 A（推荐，根治）——走官方 BuildProfile 正路**
1. `EditorBuildSettings.asset:18` 抖音 BuildProfile `enabled: 0 → 1`，作为规范出包入口。
2. 出包改为调用 `DouYinSubplatformInterface.Build(buildProfile)`（`DouYinSubplatformInterface.cs:41-81`），保持 `WeixinMiniGame + subtarget=3` 一致。
3. 删除 `AutoBuildDouyin.cs:67-74` 硬编码切目标段落。

**方案 B（若必须保留脚本）——修正目标常量**
- 改用 `BuildTarget.WeixinMiniGame`(47) + 抖音 subtarget=3，与 `New DouYin Profile.asset` 保持一致。
- 出包后**保持在 WeixinMiniGame + 抖音子平台**（不要弹回默认）。

**方案 C（兜底自愈）——加 `[InitializeOnLoad]` 自动重挂**
- 监听 `activeBuildTargetChanged` + 域重载。
- 检测到当前项目应为抖音出包场景时 → 自动把目标设回 `WeixinMiniGame + subtarget=3`，并调 `MiniGameSubplatformManager` 重新选中抖音子平台。
- → 即使目标被切走，域重载后会自动恢复，免去手动去子平台面板重载。

### 一句话
问题不在 TTSDK，而在自定义脚本 `AutoBuildDouyin.cs:70-73` 硬编码切到了错误的 `MiniGame(36)`、且出包后不恢复目标也不重挂抖音子平台；抖音工具跟着 `WeixinMiniGame` 目标走，目标一错就被卸掉。

### 3.2 视觉 / 特效 / 美术（基于实测截图）

**实测画面**（`Assets/Screenshots/play_boot_01.png` 修复前 / `play_verified_final2.png` 修复后）：

#### 立即可见的 5 个问题

1. **顶栏文字乱码**：标题和数字栏出现方块（`████`），明显是 `LegacyRuntime.ttf` 缺中文字形。**修复**：确认 `GameFont.ApplyAll` 是否覆盖所有 Text 组件；或 fallback 到 `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")` 的中文子集。
2. **主菜单宠物展示区背景是"羊皮纸/碎纸"纹理**：与背景（木地板+小清新的家）风格错位，且与"可爱猫"主体不搭。**修复**：换成纯透明 / 轻量渐变 / 留白，让宠物是绝对主角。
3. **宠物静态无反馈**：猫就一张图摆在那，不眨眼、不呼吸、不动。**修复**：加 1-2 秒随机播放 `cat_orange/idle` 动画，或呼吸缩放协程（±5%）。
4. **无任何粒子/特效反馈**：用户的点击、宠物出现、按钮 hover 都没视觉反馈。**修复**：加轻量 "汪星/光斑" 粒子 + 按钮 hover 缩放反馈。
5. **画布比例不一致**：`play_verified_final2.png` 是窄竖条（880×385 宽，比例明显被 Game View 拉扁），实际发布尺寸 750×1334。**修复**：Editor Game View 强制设为 portrait + 750×1334，所有开发截图都按真实发布比例走。
